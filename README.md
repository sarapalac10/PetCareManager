## **Propósito**

Este repositorio contiene el desarrollo del proyecto académico PetCare Manager, realizado como parte de las actividades prácticas del curso Programación Orientada a Objetos.

El objetivo del proyecto es aplicar los principios fundamentales de la Programación Orientada a Objetos (POO) para modelar y desarrollar un sistema que permita gestionar la información de un refugio de animales, incluyendo el registro de animales, adoptantes, adopciones, historial médico y donaciones.

Cada fase del proyecto representa una etapa del proceso de desarrollo de software, desde el análisis del problema y modelado conceptual hasta la implementación en código utilizando C# y .NET.

## 🚀 Sobre el Proyecto

**PetCare Manager** es una propuesta académica orientada al diseño e implementación de un sistema que permita gestionar de manera organizada la información de un refugio de animales.

El sistema busca apoyar la administración de procesos importantes como:

**-** Registro de animales rescatados

**-** Gestión del estado de los animales

**-** Registro de adoptantes

**-** Gestión del proceso de adopción

**-** Registro del historial médico

**-** Control de donaciones

## Este proyecto permite aplicar conceptos fundamentales de la Programación Orientada a Objetos, tales como:

**-** Clases y objetos

**-** Encapsulamiento

**-** Responsabilidad de clases

**-** Relación entre objetos

**-** Uso de constructores

**-** Validación de datos

**-** Organización modular del código

El desarrollo se realizó utilizando C# y .NET, implementando las clases que representan las entidades principales del sistema.

---

## 🎯 ¿Qué permite nuestro modelo?

✔ Registrar animales rescatados dentro del refugio

✔ Gestionar el estado de los animales (observación, tratamiento, disponible o adoptado)

✔ Registrar información de posibles adoptantes

✔ Crear y gestionar solicitudes de adopción

✔ Registrar eventos del historial médico de los animales

✔ Llevar control básico de donaciones al refugio

El sistema fue diseñado siguiendo los principios de la Programación Orientada a Objetos, permitiendo que cada entidad del sistema sea representada mediante clases con atributos y métodos que reflejan su comportamiento dentro del dominio del problema.
